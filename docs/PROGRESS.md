## 1. 项目一句话

上海市政府采购网（政采云）信息采集与销售提醒系统：每日 17:00 采集三类公告（意向公开/招标/中标）入库，按行政区域匹配销售，每日邮件提醒；数据带多维标签支撑分析。部署于信创服务器（x86_64 Ubuntu + PostgreSQL 16）。
