## 1. 项目一句话

上海市政府采购网（政采云）信息采集与销售提醒系统：每日 17:00 采集三类公告（意向公开/招标/中标）入库，按行政区域匹配销售，每日邮件提醒；数据带多维标签支撑分析。部署于信创服务器（x86_64 Ubuntu + PostgreSQL 16）。

### 优化：销售清单「全市」（已验收）

成功标准：
1. 销售管理区域下拉含「全市」；保存后列表出现该行
2. 挂「全市」的销售收到当天全部意向+招标+中标；同一邮箱的区县行不再另发
3. 清单无人挂全市时，仍发给 `DIGEST_ADMIN_EMAIL`
4. `npm test` 全绿

用户验收：2026-09-21 收到全市招采邮件；2026-09-28 确认运行一周无异常。

不做：企业微信/钉钉（无 webhook，改邮件）。
