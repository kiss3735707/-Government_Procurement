# 上线准备清单与待细化事项

版本：v1.0
日期：2026-08-15
配套：《政府采购信息采集与销售提醒系统-设计方案.md》（v1.1）、《数据库设计说明书.md》

> 用法：本文档是"除了技术方案，还需要准备什么"的总清单。分四类：
> **A. 你/公司需要提供的** | **B. 需要共同决策的** | **C. 我已确认（技术验证结论）** | **D. 上线前必须完成的落地项**

---

## A. 需要你 / 公司提供

| # | 事项 | 说明 | 需要时间点 |
|---|---|---|---|
| A1 | **区域-销售清单 CSV** | 销售姓名 + 邮箱 + 负责区域。格式：`sales_name,sales_email,region,note,is_active`（region 用区级，如"浦东新区"；一个销售多区写多行）。我会做归一化，见 C2 | M5 前（约 2 周后），先给初版即可跑通邮件 |
| A2 | **公司 SMTP 配置** | 主机 / 端口 / 账号 / 密码 / 发件人邮箱 | M4（日报邮件）前 |
| A3 | **信创服务器** | 2C4G + 100GB，Ubuntu 22.04/24.04，海光/兆芯 x86_64，可访问外网；SSH 访问方式（账号/密钥） | M6 部署前 |
| A4 | **管理员/告警接收邮箱** | 采集失败、未匹配区划"待分配池"通知发给谁 | M4 前 |
| A5 | **日报邮件收件人范围确认** | 是否所有销售都发？有无停发名单？ | M4 前 |

## B. 需要共同决策的（每项给默认建议）

| # | 决策点 | 我的建议 | 影响 |
|---|---|---|---|
| B1 | **"招标中"是否纳入日报**（已确认纳入） | 纳入（你已确认） | 已定 |
| B2 | **日报里意向公开的呈现粒度** | 按**明细行**（每个采购项目一条）呈现，不是按公告 | 更贴合"商机"视角，销售看到的是具体项目 |
| B3 | **金额区间划分** | `<50万 / 50-200万 / 200-1000万 / >1000万` | 标签和分析维度；可按你们客单价调整 |
| B4 | **未匹配区划的处理** | 进"待分配池"，日报单列发管理员，不静默丢弃 | 保障无遗漏 |
| B5 | **日报是否带 CSV 附件** | 默认正文即可，CSV 附件二期再加 | 邮件简洁性 |
| B6 | **邮件发送时间** | 17:00 采集、18:00 日报 | 可调 |
| B7 | **是否下载招标文件附件存档** | 二期再做（一期只存附件链接） | 一期聚焦核心流程 |
| B8 | **管理界面账号** | 内网使用 + 简单账号密码（或与公司统一登录集成，二期） | 安全与便利平衡 |
| B9 | **产品线/关键词清单** | 你们销售关注哪些产品方向（如"实验室设备""信息化""医疗"），用于人工打标和意向匹配 | 标签体系价值的核心输入 |
| B10 | **数据保留期限** | 永久保留（量小无压力） | 已默认 |

## C. 技术已验证结论（写进方案的事实依据）

| # | 结论 | 证据 |
|---|---|---|
| C1 | 三个栏目接口全部可用 | 意向公开 82,436 / 招标中 54,374 / 中标 75,959 条，分页、时间过滤、详情接口均实测通过 |
| C2 | **区划名称有两种写法**，必须归一化 | "浦东新区"（多数）与"上海市浦东新区"（中标结果里常见）并存，共 28 种去重名称，对应上海 16 区+本级。**销售清单只写标准名，系统自动把两种写法归一到标准区** |
| C3 | 意向公开的金额、预计采购月可稳定解析 | 正文表格解析实测：`1726000.00 / 2026-09` 等均正确提取 |
| C4 | 招标正文含预算/最高限价/开标时间/资金性质 | 详情接口实测 |
| C5 | 中标正文含成交金额；供应商部分在正文、部分在附件 PDF | 附件 PDF 解析列入二期 |
| C6 | 项目时间线数据可用（公告→更正→结果→合同） | announcementLinkDtoList 实测，二期做全生命周期 |
| C7 | robots.txt 返回 307 重定向（未直接暴露规则） | 采集以低频、礼貌策略为准（≥500ms 间隔、仅当日增量） |
| C8 | 站点为政采云 SPA，必须走接口采集 | HTML 无数据，直接抓 HTML 无效 |

## 下一步建议（按依赖排序）

```
现在就能做：M1 采集原型（不需要等任何输入）
  ↓
等 A1（销售清单）+ A2（SMTP）→ M4 日报邮件跑通
  ↓
等 A3（服务器）→ M6 部署上线
  ↓
B9（产品线清单）→ 二期打标与意向匹配增强
```

**结论：你现在唯一需要尽快准备的是 A1（销售清单 CSV）和 A2（SMTP 配置）；B9（产品线清单）影响二期价值但不阻塞一期；其余都是我在开发中会处理的技术项。**
